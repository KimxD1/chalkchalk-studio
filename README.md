# 찰칵찰칵 사진관 - 프로토타입

배경 프리셋 합성 + NFC 결제까지 **한 페이지 안에서** 끝나는 포토부스 프로토타입입니다.
전자칠판(Android) 자체 브라우저에서 직접 실행하는 것을 전제로 합니다.

## 구조
```
chalkchalk-studio/
├── package.json
├── server.js            # 정적 파일 서버 (세션/결제 중계 없음 - 전부 한 페이지에서 처리)
└── public/
    ├── backgrounds/      # 배경 프리셋 이미지
    ├── index.html        # 시작 → 배경 선택 → 촬영 → 결제(NFC) → 완료
    ├── main.js
    └── main.css
```

## 로컬 실행 방법
```bash
npm install
npm start
# http://localhost:3000
```

## Azure App Service로 배포하기
1. 이 프로젝트 전체(package.json이 최상위에 오도록)를 GitHub 저장소에 올립니다.
2. Azure Portal에서 **Web App(앱 서비스)** 를 새로 만듭니다.
   - 게시: 코드, 런타임 스택: **Node 20 LTS**, 운영체제: **Linux**, 지역: 가까운 곳(예: Korea Central)
   - 요금제: 테스트는 **F1(무료)**, 실제 매장 운영은 **B1 이상**을 권장합니다.
3. Web App의 **배포 센터(Deployment Center)** 에서 GitHub 저장소/브랜치를 연결하면 자동 배포됩니다.
4. 배포가 끝나면 `https://앱이름.azurewebsites.net` 이 실제 운영 주소가 됩니다.
   전자칠판 내장 브라우저에서 이 주소로 접속하면 촬영부터 결제까지 한 화면에서 끝납니다.
   (이제 세션 중계용 WebSocket이 없으므로, "웹 소켓 켜기" 설정은 필요 없습니다.)

## NFC 결제 (같은 페이지에서 처리)
Web NFC API(`NDEFReader`)는 **Android + Chrome** 조합에서만 동작합니다. 따라서 이 페이지는
**전자칠판 자체 내장 시스템(Android)의 브라우저**에서 직접 열어야 NFC가 인식됩니다.
PC를 HDMI로 연결해 미러링하는 방식으로는 인식되지 않습니다 (자세한 배경은
`NFC_테스트_체크리스트.md` 참고).

- 촬영 후 결제 화면으로 넘어가면 "화면 눌러서 결제 시작하기" 버튼이 나옵니다.
  Web NFC는 보안 규격상 사람이 직접 화면을 탭한 직후에만 스캔을 시작할 수 있어서,
  완전 자동 스캔은 불가능합니다 - 탭 한 번만 추가된 구조입니다.
- NFC가 지원되지 않는 환경(테스트 중인 일반 PC 등)에서는 "테스트용: 결제 완료 처리 (데모)"
  버튼으로 결제 없이 흐름을 확인할 수 있습니다.
- 실제 카드사 결제 승인은 아직 연동되어 있지 않습니다 (`main.js`의 `processPayment()` TODO 참고).
  현재는 태그가 인식되면 바로 성공 처리되는 데모 단계입니다.

## 배경 프리셋
`public/backgrounds/`에 있는 이미지 중 하나를 골라 바로 촬영에 사용합니다. 네트워크 호출이
없어 즉시 반응합니다.

**실제 이미지로 교체하는 방법**: `public/main.js` 맨 위의 `PRESETS` 배열에 파일 경로와 이름만
적으면 됩니다. 투명도가 있는 이미지는 필요 없습니다 - 사람은 실시간으로 별도로 오려내서
합성하므로, 배경은 화면을 꽉 채우는 불투명한 이미지면 충분합니다. 권장 비율은 16:9
(예: 1920×1080)입니다.

## 화면 동작
- 촬영 화면은 좌우 반전(거울 모드)되어 있어, 실제 거울처럼 움직입니다. 저장되는 사진도
  이 반전된 모습 그대로 저장됩니다.
- 화면비는 16:9입니다.

3. 카드/결제 정보가 클라이언트(브라우저)에 노출되지 않도록 PG사 SDK를 통해서만 처리하세요.
